# 업적 전용 컬렉션 화면 기준

기존 순위표의 밝은 바탕과 선 아이콘, PageHeading 구성을 이어간다. 매일 돌아오는 플레이어가 출석 버튼과 다음 보상을 먼저 확인하고, 완료한 보상을 꾸미기에서 장착하는 화면이다.

- 우선순위: 오늘 출석 → 연속 출석/최고 기록 → 전용 보상 4종 → 접힌 추가 업적 계획.
- 보상은 실제 SVG 프로필·게임 타일 미리보기로 보여준다. 출근왕은 왕관·가방·시계, 승리의 선봉은 투구·월계수다. 기존 UI 선 아이콘과 수집품 삽화의 용도를 구분한다.
- 375×812 단일 열, 768×1024와 1440×900 두 열. 기존 색상·보드 숫자 대비·장애물 구분 유지.
- 로딩: 값을 꾸며내지 않고 불러오는 중 문구, 출석 비활성.
- 빈 기록: 서버가 반환한 0일부터 시작. 게스트에게 0 진행률을 제시하지 않는다.
- 오류: 조회·출석 저장 오류를 구분하고 재시도 허용. 장착 소유권은 조회 성공한 계정별 해금 내역으로 확인.
- 일부 정보: 지갑과 업적은 독립 조회. 한쪽 오류가 기존 무료 스킨 장착을 막지 않는다.
- 성공: 오늘 출석 완료, 새 보상 안내, 영구 해금, 내 꾸미기로 이동. 자동 장착하지 않는다.
- 권한: 게스트 로그인 안내, 잠긴 보상은 미리보기와 조건만. 계정 전환 시 이전 응답·해금 안내를 폐기한다.
- 접근성: 버튼의 상태/이름, 진행도 이름, 상태 알림, 대화상자 키보드 열기·닫기와 포커스 복귀 확인.

검증: achievement-unlocks.browser.mjs, achievement-assets.browser.mjs, SQL 업적 테스트 및 실제 PostgreSQL 동시성 검사. 디자인 근거는 같은 프로젝트의 순위표·꾸미기·visual-asset-guide.md다.
