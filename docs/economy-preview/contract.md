# 업적·상점 화면 기준

> 업적·상점 미리보기 단계의 계약이다. 준비 중 업적과 구매 비활성 설명은 당시 범위이며 현재 [업적](../achievements-and-shop.md)·[상점](../cosmetic-shop.md)은 후속 구현을 포함한다.

- 기존 배경·카드·강조색과 `PageHeading`, `GameEmblem` 선 아이콘을 유지한다.
- 이 기록은 상점과 접힌 준비 중 업적 6종을 검증한다. 실제 해금 업적 4종의 화면 기준은 [별도 계약](../achievement-rewards/contract.md)을 따른다. 준비 중 정의에 집계되지 않은 숫자와 가짜 진행률을 표시하지 않는다.
- 상점은 상품을 12개씩 보여주며 모바일 3열·태블릿 4열·데스크톱 6열로 구성한다. 등급 변경 시 첫 페이지로 이동한다.
- 기존 스킨 미리보기·레전더리 합성 모션을 재사용하고, 구매 버튼은 비활성이다. 상세 열기와 재생으로 장착 상태나 잔액을 바꾸지 않는다.
- 375×812, 768×1024, 1440×900, 게스트와 로그인 계정, 키보드 진입·닫기·포커스 복귀를 확인한다.

검증: `apps/web/tests/economy.browser.mjs`, `apps/socket/tests/economy-catalog.test.ts`. 준비 중 카탈로그·문구에는 실제 소유권이나 지급 완료를 암시하지 않는다.
