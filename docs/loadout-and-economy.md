# 코인 · 스킨 · 능력 설계

## 이번 구현 범위

- `/loadout`은 코인 잔액과 보드 스킨 20종·프로필 아이콘 6종을 보여준다. 능력 설정은 `/find-match`의 **특수 능력** 모달로 옮겼다.
- 꾸미기 카드는 이미지와 제목 중심으로 모바일 3열·태블릿 4열·큰 화면 6열, 스킨은 페이지당 12개다. 등급 필터와 **보유 중인 것만** 필터를 함께 적용한다. 잠긴 카드도 클릭할 수 있으며 상세 모달에 해금 조건을 표시한다.
- 로그인 계정은 현재 카탈로그를 무료로 사용할 수 있다. 게스트는 전용 아이콘·클래식 보드·기본 능력(X 1개 제거)으로 고정한다. 이전 게스트 쿠키의 언어·키 설정은 유지하고 꾸미기 선택만 기본값으로 읽는다. 로그인 계정의 선택은 로그아웃 후에도 보존한다.
- 서버는 게스트가 요청한 커스텀 아이콘·스킨을 무시한다. 프로필 아이콘은 원형이며 여우의 노을, 부엉이의 밤하늘, 드래곤의 산, 고양이의 궤도, 토끼의 구름, 로봇의 회로 배경으로 구분한다.
- 아이콘의 업적 해금은 추후 도입 예정이다. 현재 조건은 로그인이고, 업적 조건·진행도·보상 지급은 구현하지 않는다.
- 능력 모달은 각 이름에 한 줄 효과 요약을 붙인다. 누르면 상세 효과·제약과 선택 버튼이 펼쳐진다. 게스트도 내용을 볼 수 있지만 기본 능력만 사용할 수 있다.
- 코인 지갑은 서버에서 최초 잔액 0으로 생성한다. 지급·차감·구매는 아직 구현하지 않는다. 능력 5종은 실제 대전에 적용되며 서버가 충전·발동·대상을 판정한다.
- 숫자 타일·보드 스킨의 렌더링과 게임 판정은 기존 공통 컴포넌트를 사용한다. 방해블록 식별과 숫자 색상은 유지한다.

## 실제 능력 5개

`/find-match`에서 경기 전 하나를 선택한다. 기본 능력은 **X 제거**이며 게스트와 선택하지 않은 계정 모두 사용한다. 능력 선택은 첫 입장 때 고정되고 재접속이나 경기 중 설정 변경으로 바뀌지 않는다. 아이콘은 `apps/web/public/ability-icons/`의 전용 SVG 5종이다.

| ID / 이름 | 효과 | 제한 |
| --- | --- | --- |
| `clear-x` / X 제거 | 내 보드에서 가장 오래된 X 블록 **1개** 제거 | 하드·숫자·도착 예정 공격 유지. X가 없으면 충전 유지 |
| `spawn-pause` / 숨 고르기 | 내 다음 유효 이동 3회 동안 일반 숫자 생성 중지 | 상대 장애물은 정상 도착. 무효 이동은 횟수 유지 |
| `frost-wave` / 감속 | 1초 예고 후 3초 동안 상대 이동 간격을 최소 0.4초로 제한 | 공격·능력 사용은 가능. 중첩·연장하지 않으며 재접속 대기 동안 시간 정지 |
| `anchor-tile` / 알박기 | 최고 숫자 타일 1개를 다음 유효 이동 3회 동안 고정 | 동률이면 오래된 타일. 같은 숫자를 고정 자리에서 병합 가능하며 병합 후에도 남은 횟수 유지. 발동 즉시 움직일 수 없게 되는 경우 거절 |
| `swap-32` / 32 자리 바꾸기 | 상대의 32 하나와 2·4·8·16 중 하나를 서버 난수로 위치 교환 | 32끼리·장애물·고정된 타일은 제외. 대상이 없으면 충전 유지. 점수·공격권·새 타일 생성 없음 |

- 시작 충전은 0. 실제 병합으로 얻은 점수를 누적해 **1024마다 1회**, 최대 1회분(1024)까지 저장한다. 가득 찬 동안 추가 점수는 버린다. 사용 후 0부터 다시 충전한다.
- 지속 중인 내 생성 중지·알박기는 재사용할 수 없다. 이미 감속 중인 상대에게는 다시 감속을 걸 수 없다. 거절하면 충전을 유지한다.
- 무효 이동·능력 발동만으로 충전하지 않는다. 능력 사용은 이동 횟수를 소모하지 않는다.
- 서버가 점수·대상·난수·유효 이동·감속 간격을 검증한다. 클라이언트는 능력 사용 의도만 전송한다.
- 양쪽 재접속 대기 중 발동과 이동을 차단하고, 충전·지속 이동 수·감속 남은 시간을 복원한다. 서버 재시작 후 진행 경기 복구는 기존과 동일하게 지원하지 않는다.
- 능력에 의해 보드가 바뀐 뒤에도 이동 불가 승패를 판정한다. 일반 이동에서 2048을 만든 경우가 우선한다.
- `/tutorial`은 기존 5단계 뒤 **기본 능력 사용** 단계를 추가했다. 연습용 충전 1회를 제공하며 X 2개 중 정확히 하나만 제거하고 하드·숫자는 유지한다. 실전과 같은 제거 함수를 사용한다.

충전 1024·감속 3초·알박기 3회는 첫 플레이테스트용 수치다. 장기 선택률과 승률은 아직 확인하지 않았다.

### 선택 저장 호환성

- 저장된 `null`은 X 제거로 표시·장착한다. 기존 `clear-x`도 같은 능력이다.
- 폐기된 능력 ID는 읽을 때 기본 능력으로 처리한다. 언어·키 설정·계정 스킨과 아이콘은 보존한다.
- `20261015181708_five_abilities.sql`은 DB 허용 목록에 새 3개 ID를 추가하며 연결된 Supabase에도 적용·확인했다. 기존 행과 이전 ID는 삭제하지 않는다.

## 코인 지급 추천안 — 미확정

첫 실험은 **일반전·랭크전 정상 완료 10코인 + 승리 5코인**, 친구전 0코인으로 시작하는 것을 제안한다. 패배해도 보상이 남고, 승리 보너스를 작게 두어 고의 패배·실력 차이로 생기는 격차를 줄인다. 가입·출석 보상은 초기에는 생략해 플레이 보상부터 측정한다.

지급 전에는 양쪽의 최소 유효 이동 수·경기 시간, 탈주·조기 기권, 반복 상대, 일일 지급 상한을 함께 정해야 한다. 구체적 기준은 평균 경기 길이를 수집한 뒤 확정한다. 무승부는 완료 보상만, 중복 결과 수신은 같은 경기 ID로 한 번만 지급한다. 게스트와 자기 계정 간 대전에는 지급하지 않는다.

가격도 미확정이다. 기본 스킨은 무료로 유지하고, 첫 추가 스킨까지 대략 10–20경기 정도의 획득 시간을 목표로 실험한다. 능력 효과의 균형이 검증되기 전에 능력 판매를 열지 않는다.

향후 지급·구매 구현은 서버 거래 기록과 원자적 잔액 변경을 사용한다. 거래 유형·경기/구매 ID의 고유 제약으로 재시도를 중복 지급·중복 차감 없이 처리하고, 잔액이 음수가 되는 구매를 거절한다. 이 거래 계층은 이번 화면 구현에 미리 추가하지 않는다.
