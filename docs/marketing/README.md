# 2048 Duo 홍보 준비

조사·작성: 2026-10-31 KST. **검토용 초안이며 게시·예약·광고 집행·외부 연락은 하지 않았다.**

첫 홍보는 **“256을 만들면 상대에게 X가 날아가는 1대1 2048”**로 시작한다. 실제 대전 장면으로 규칙을 보여주고, 친구 한 명과 방 코드로 한 판 하는 동선에 집중한다. 무작위 매칭의 현재 이용자 수나 대기 시간은 확인하지 않았다.

## 준비된 것

| 파일 | 내용 |
|---|---|
| [조사와 벤치마크](research.md) | 직접 확인한 X 글 2건, 개발자 회고·공식 캠페인, 대상 이용자와 채널 선택 근거 |
| [게시물 초안](posts.md) | 한국어 X 8개, 영어 X 3개, 3개 글짜리 스레드, 프로필 소개, 커뮤니티용 글과 답변 |
| [촬영·운영안](runbook.md) | 영상 2편의 초 단위 촬영안, 14일 게시 순서, 성과 해석과 게시 전 조건 |
| [기록표](tracking.csv) | 게시 후 24시간·72시간 지표를 적는 빈 표. 실제 성과 데이터 아님 |

첫 실행 묶음은 **X01 + 영상 V1 + `/find-match` 링크**다. [촬영안](runbook.md)의 실제 장면이 확보되고 게스트 친구전이 정상적으로 끝나는지 확인한 뒤 사용한다. 나머지 초안을 한꺼번에 게시하지 않는다.

## 이번 캠페인의 선택

- **첫 대상:** 2048 규칙을 아는 사람과, 친구에게 가볍게 웹 게임을 보내는 사람. 이는 제품·사례에 근거한 초기 가설이며 고객 조사 결과는 아니다.
- **약속:** 익숙한 숫자 합치기로 상대의 보드를 방해하며 겨룬다.
- **핵심 장면:** 내 보드에서 128+128 → 256, 상대의 다음 유효 이동에 X 등장.
- **행동:** `대전 찾기 → 친선전 → 방 만들기`, 친구는 `친선전 → 방 참여하기`에서 6자리 코드 입력.
- **말투:** 짧은 한국어 해요체. 제작자가 눈앞의 규칙을 설명한다. 사용자의 개인 문체를 학습했다는 뜻은 아니다.
- **기본 범위:** 한국어 X 중심, 해외 반응을 볼 영어 대체안, 같은 플레이 원본을 쓰는 Shorts/Reels. 예산·기존 계정·팔로워 정보가 없으므로 첫 2주는 유료 광고 없이 검증하는 안이다.

‘AI 티를 줄인다’는 요청은 상투어·억지 감탄·가짜 일화를 없애는 편집 기준으로 반영했다. 이용자 행세, 허구의 후기, 존재하지 않는 인기·기록은 쓰지 않는다. AI 사용 공개를 요구하는 커뮤니티에서는 해당 규칙을 따른다.

## 제품 근거와 현재 확인 범위

작성 기준은 최신 `origin/staging`의 `1abf89e`다. 조사 당시 `origin/main`의 `5d6e144`와 파일 트리는 같았다. 브랜치 일치만으로 해당 커밋의 운영 배포를 증명하지 않는다.

| 사용할 주장 | 근거 | 범위·주의점 |
|---|---|---|
| 5×5 실시간 1대1 대전 | [게임 규칙](../game-design.md), [규칙 화면](../../apps/web/src/app/how-to-play/page.tsx) | 협동 게임이 아니다 |
| 새 256은 X, 새 512는 고정 블록 공격 | [게임 코어](../../packages/game-core/src/index.ts) | 공격은 상대의 다음 유효 이동에 적용된다. 숫자 타일 자체를 보내는 것은 아니다 |
| 대전에서 1024를 만들면 승리 | [서버 판정](../../apps/socket/src/game.ts) | 상대 이동 불가로도 승리. 솔로 목표와 혼동하지 않는다 |
| 일반전·친구전은 게스트 참가 | [README](../../README.md), 운영 공개 화면 관찰 | 랭크전까지 무가입이라고 쓰지 않는다 |
| 친구와 6자리 방 코드로 입장 | [방 생성](../../apps/web/src/components/widget/create-room-controls.tsx), [입장 폼](../../apps/web/src/components/widget/join-room-form.tsx) | 친구 목록·메시지 기능은 로그인 필요 |
| 혼자 할 때 4×4 타임어택·무한 모드 | [싱글플레이](../solo-time-attack.md) | 대전에는 방해 공격, 솔로에는 없음 |
| 한국어·영어, 키보드·스와이프·화면 버튼 | [설정](../settings.md), [보드](../../apps/web/src/components/2048/board.tsx) | 이번 작업에서 실제 휴대폰 플레이를 검증하지 않았다 |

2026-10-31 운영 브라우저에서 홈과 `/find-match`, `친선전` 메뉴의 `방 만들기`·`방 참여하기`를 게스트 상태로 확인했다. 실제 대전 완료, 신규 가입 메일, 모바일 실기기, X 링크 카드 렌더링은 이번 작업의 검증 범위가 아니다.

## 게시 전에 남은 일

1. 최신 운영에서 게스트 두 명으로 친구전 한 판을 끝내고 V1·V2를 촬영한다. 기존 QA 스크린샷은 오래된 공격 버튼·단축키·개발 배지가 보여 재사용하지 않는다.
2. 게시 계정과 한국어/영어 운영 비중을 정한다. 계정 정보가 없어 계정 생성·프로필 변경은 하지 않았다.
3. 실제 모집 시간을 확보했을 때만 함께 플레이할 시간을 공지한다. 아직 이벤트 일시를 약속하지 않았다.
4. 가입·랭크를 홍보하려면 [마지막 출시 점검](../launch-readiness.md)의 SMTP 미해결 기록이 해소됐는지 확인한다. 10월 23일 기록이고, 현재도 미해결이라고 단정하지 않는다.

공유용 OG·X 카드 코드는 [이미 있다](../../apps/web/src/lib/site-metadata.ts). [1200×630 이미지](../../apps/web/src/app/opengraph-image.tsx)는 브랜드 카드이며 게임플레이 캡처가 아니다. 새 랜딩 페이지·가입 폼·추적 코드·의존성은 추가하지 않았다.

적용한 스킬: `ecc:marketing-campaign`, `ecc:market-research`, `ecc:brand-voice`, `ecc:content-engine`. 준비 요청 범위에 맞춰 포지셔닝과 카피를 함께 검토할 수 있도록 작성했다. 이메일 시퀀스, LinkedIn, 경품, 유료 광고, 자동 게시 봇은 이번 범위에서 제외했다.
