# 게시물 초안

모든 글은 **게시 전 초안**이다. 코드 블록 안이 게시문이고, 밖은 운영 메모다. X 글은 링크를 본문에 두는 안으로 준비했다. 링크를 댓글로 빼면 더 퍼진다는 주장은 검증하지 않았다.

## 편집 기준

제품 문구의 근거는 [게임 규칙](../game-design.md), [게임 방법 화면](../../apps/web/src/app/how-to-play/page.tsx), [현재 공유 설명](../../apps/web/src/lib/site-metadata.ts)이다. 기존 개인 X 글을 제공받지 않았으므로 개인 말투 모사가 아니라 제품용 임시 편집 기준이다.

- 첫 줄에 실제 행동이나 화면에서 생긴 일을 쓴다. 한 글에 중심 장면 하나.
- 숫자는 규칙을 설명할 때만 쓴다. 플레이 시간·이용자 수·승률은 실측 없이 쓰지 않는다.
- 한국어는 짧은 해요체, 영어는 평범한 문장과 일반적인 대소문자. 의미 없는 줄바꿈·이모지·해시태그 묶음은 넣지 않는다.
- 실제로 없던 “친구랑 밤샜다”, “다들 중독됐다”, “드디어 수천 명” 같은 경험담을 만들지 않는다.
- 일부러 오타·비문·과도한 웃음 표시를 넣지 않는다. “혁신적인”, “역대급”, “새로운 경험”, “많은 관심 부탁드립니다”를 지운다.
- 질문은 실제 플레이 피드백을 받을 때만 한다. 모든 글 끝에 질문을 붙이지 않는다.
- 제작자 계정이면 “만들었어요”를 쓸 수 있다. 제3자가 우연히 발견한 게임인 것처럼 소개하지 않는다.

## X 프로필

표시 이름 제안: `2048 Duo`. 사용 가능한 핸들은 확인하지 않았다.

한국어 소개:

```text
숫자를 합쳐 상대 보드를 막는 1대1 2048. 브라우저에서 친구와 방 코드로 한 판. 개발·업데이트 기록을 올립니다.
```

영어 대체 소개:

```text
1v1 2048 in your browser. Merge tiles, send obstacles, race to 1024. Play with a friend using a room code.
```

웹사이트 필드: `https://www.2048duo.io/find-match`. 고정 글 후보는 X01. 프로필 변경·고정은 수행하지 않았다.

## 한국어 X — 8개

### X01 · 첫 소개 / 고정 후보

소재: V1의 256 합성 → 상대 X 유입. 목표: 친구 대전 진입.

```text
2048에 상대방을 넣었어요.

128 두 개를 합쳐 256을 만들면 상대 보드에 X가 날아갑니다.
친구랑 방 코드로 한 판 할 수 있어요. 가입 없이 됩니다.

https://www.2048duo.io/find-match
```

### X02 · X의 규칙

소재: X가 숫자와 같이 움직이지만 합쳐지지 않는 실제 플레이.

```text
이 X는 움직이는데, 합쳐지지는 않아요.

상대가 256을 만들면 내 보드에 들어옵니다.
숫자 정리하다가 갑자기 자리 하나가 아까워지는 순간.
```

### X03 · 친구 초대

소재: V2의 방 만들기·입장·두 보드. 공개 이미지에는 이미 종료된 방 코드만 사용.

```text
친구한테 보내는 건 방 코드 6자리.

대전 찾기 → 친선전 → 방 만들기.
상대는 방 참여하기에서 코드를 넣으면 됩니다.
둘 다 게스트로 할 수 있어요.

https://www.2048duo.io/find-match
```

### X04 · 512 공격

소재: 실제 512 합성 → 상대의 유효 이동 → 고정 블록 유입·이후 이동.

```text
256은 움직이는 X.
512는 안 움직이는 블록.

2048 Duo에서는 큰 숫자를 만드는 게 상대 보드를 막는 방법이기도 해요.
```

### X05 · 승리 목표

소재: 실제 대전에서 1024 타일 생성과 승리 표시. 승리 장면 확보 후 사용.

```text
이름은 2048인데, 대전은 1024를 만들면 이깁니다.

그전에 상대 보드가 막혀도 이겨요.
내 숫자만 보고 있으면 상대가 보낸 블록을 놓치기 쉽습니다.
```

### X06 · 혼자 온 사람

소재: 4×4 솔로 보드. 대전 클립을 붙이지 않는다.

```text
같이 할 친구가 지금 없으면 싱글플레이도 있어요.

4×4 보드에서 타임어택이나 무한모드로 할 수 있습니다.
여기서는 상대가 보내는 블록이 없어요.

https://www.2048duo.io/solo
```

### X07 · X 제거

소재: 실제로 충전된 기본 능력을 쓰는 장면. 자동 방어나 무한 사용으로 보이게 편집하지 않는다.

```text
X 하나만 없으면 합칠 수 있는데.

기본 능력은 내 보드의 X 하나를 지우는 거예요.
충전됐을 때 스페이스바나 보드 아래 버튼으로 씁니다.
```

### X08 · 짧은 대전 초대

소재: X01과 다른 실제 대전 클립. 아직 없는 후기나 패배 일화는 붙이지 않는다.

```text
숫자는 내가 합쳤는데, 곤란해지는 건 상대방.

256을 만들면 X를 보내는 1대1 2048입니다.
친구 한 명이랑 해보세요.

https://www.2048duo.io/find-match
```

## 영어 X — 대체안 3개

한 계정에서 한국어 게시물 직후 번역문을 연달아 올리는 기본안은 아니다. 해외용 계정을 쓰거나, [운영표](runbook.md)의 영어 슬롯에서 한 개씩 시험한다.

### EN01 · Mechanic

```text
I made a 1v1 version of 2048.

Make a 256 tile and an X heads to your opponent's board. You can play with a friend using a room code. No signup needed for friend matches.

https://www.2048duo.io/find-match
```

### EN02 · Board pressure

```text
An X moves with your tiles, but it won't merge.

Your opponent made a 256. Now you have one less empty cell to work with.

2048 Duo, a 1v1 tile game in the browser.
```

### EN03 · Friend match

```text
Bring one friend and a six-character room code.

Race to 1024 while sending obstacles into each other's boards. Guest friend matches work without an account.

https://www.2048duo.io/find-match
```

## X 스레드 — 규칙 설명 3개

목적: 첫 소개를 본 사람이 규칙을 더 보고 싶을 때. 각 글이 다음 내용을 추가한다. 별도 발행일은 반응을 보고 정한다.

### T01

```text
2048 Duo는 둘이 하는 2048이에요.

5×5 보드에서 숫자를 합치고, 256을 새로 만들면 상대에게 X를 보냅니다.
내 보드를 키우는 동안 상대 보드도 조금씩 막혀요.
```

### T02

```text
512를 만들면 움직이지 않는 블록을 보냅니다.

공격은 상대가 다음으로 유효한 이동을 했을 때 들어가요.
1024를 만들거나 상대가 더 움직이지 못하면 승리입니다.
```

### T03

```text
친구와 하려면 대전 찾기 → 친선전에서 방을 만들고 6자리 코드를 보내면 됩니다.

친구전은 가입 없이 할 수 있어요.

https://www.2048duo.io/find-match
```

## Shorts / Reels 캡션

V1 제목: `256을 만들었더니 상대 보드에 X가 생겼다`

```text
128+128=256. 그다음은 상대 차례.
숫자를 합쳐 장애물을 보내는 2048 Duo입니다.
브라우저에서 친구와 방 코드로 대전할 수 있어요.
```

V2 제목: `친구랑 2048 하는 방법`

```text
한 명은 방을 만들고, 한 명은 코드로 들어오기.
같이 숫자를 합치지만 서로의 보드를 막습니다.
2048 Duo / www.2048duo.io
```

Shorts에서는 외부 주소가 클릭된다고 가정하지 않는다. 화면 끝에 읽을 수 있는 도메인을 보여주고, 실제 계정에서 가능한 채널 프로필 링크를 확인한다. 프로필 변경은 아직 하지 않았다.

## 커뮤니티 초안

### 한국어 게임 소개 게시판용

사용처는 아직 지정하지 않았다. 해당 게시판의 홍보 허용 여부·작성자 자격을 확인한 뒤 사용한다. 개발자가 올리는 글이라는 사실을 첫 문장에 둔다.

제목: `256을 만들면 상대에게 장애물을 보내는 1대1 2048을 만들었어요`

```text
2048 Duo를 만들고 있어요. 2048을 둘이 겨루는 브라우저 게임입니다.

5×5 보드에서 256을 만들면 상대에게 X를 보내고, 512를 만들면 움직이지 않는 블록을 보냅니다. 대전은 1024를 만들거나 상대 보드가 막히면 이겨요.

친구랑 하려면 대전 찾기 → 친선전에서 방을 만들고 6자리 코드를 보내면 됩니다. 친구전은 둘 다 가입 없이 들어갈 수 있어요. 혼자 하는 4×4 모드도 있습니다.

플레이: https://www.2048duo.io/find-match
```

실제 대전 영상 V1을 첨부한다. 게시판이 링크·영상 형식을 제한하면 그 형식에 맞춘다. “우연히 찾은 게임”으로 제목을 바꾸지 않는다.

### Reddit r/WebGames용

게임명으로 시작하는 제목과 직접 게임 링크를 쓰는 커뮤니티다. 최근 3개월 동일 게임 게시 여부·규칙을 발행 직전에 검색한다. 이 계정의 게시 이력은 확인하지 않았다. [규칙 근거](research.md).

제목:

```text
2048 Duo — a browser tile game with 1v1 obstacle battles and solo modes
```

링크 포스트 목적지: `https://www.2048duo.io/solo`. 혼자 방문해도 시작할 수 있는 실제 모드로 연결한다. 게시 직전 로그아웃 상태에서 정상 플레이를 확인한다.

작성자 댓글 초안:

```text
I'm the developer of 2048 Duo. The link opens solo play, which uses a 4×4 board.

The 1v1 mode uses a 5×5 board: making a 256 sends an X to the other player, and making a 512 sends a fixed block. Reach 1024 or leave your opponent unable to move to win.

To play together, open Find Match, choose Friend Match, and share the six-character room code. Guest friend matches don't require signup.
```

r/IndieGaming에는 이 문안을 그대로 게시하지 않는다. 해당 커뮤니티는 게임 제작 또는 홍보에 GenAI가 쓰이면 용도 공개를 요구하고, GenAI 의존도가 높은 게임의 게시도 제한한다. 이번 문안 준비에는 AI가 사용됐다. 개발 전체의 사용 범위는 별도 확인이 필요하다. r/playmygame은 실제 플레이테스트 목적에 맞는 별도 요청이 있을 때 사용한다.

## 실제 질문이 왔을 때의 답변

답변은 해당 질문이 있을 때만 사용한다. 홍보 문구를 무관한 글의 댓글에 반복하지 않는다.

**“가입해야 하나요?”**

```text
일반전과 친구전은 가입 없이 됩니다. 랭크전은 계정이 필요해요. 친구랑 하실 거면 친선전에서 방 코드를 쓰시면 됩니다.
```

**“친구가 없는데요?”**

```text
싱글플레이에서 4×4 타임어택이나 무한모드로 할 수 있어요. 일반전도 있지만, 상대가 대기 중이어야 매칭됩니다.
```

**“2048인데 왜 1024에서 끝나요?”**

```text
현재 대전의 승리 목표는 1024로 설정해뒀어요. 상대가 움직일 수 없게 돼도 이깁니다.
```

**“버그가 있어요.”**

```text
어느 화면에서 어떤 동작을 하셨는지 알려주실 수 있을까요? 사용한 브라우저와 함께 남겨주시면 확인하는 데 도움이 됩니다. 비밀번호나 방 코드는 보내지 않으셔도 됩니다.
```

수정 전에는 “고쳤습니다”라고 답하지 않는다. 아직 없던 질문을 실제로 받은 것처럼 게시물에 인용하지 않는다.
