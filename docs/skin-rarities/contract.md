# Skin rarity design contract

- Keep the warm tabletop style, existing skin IDs, matched board/tile corners, and free pricing.
- Nine skins: three common color variants, two rare tile patterns, two epic board/tile themes, two legendary cat/rabbit character themes.
- Share number-tile rendering between catalog and playable boards. Character art stays decorative; high-contrast numbers and existing accessible tile names remain. X/hard blocks retain their existing appearance.
- All/common/rare/epic/legendary filters, visible text badges, six items per page, independent ability page state. Filtering never changes the equipped skin.
- Verify 375×812, 768×1024, 1440×900, Korean/English, keyboard controls, persistence, and migration acceptance of every catalog ID while rejecting unknown IDs.
- No purchase, rewards, or gameplay/ability effects in this change.
- Follow-up direction: keep optional character skins, but replace playful tier faces with metallic shield emblems and a restrained slate/gold leaderboard. Preserve all Elo thresholds, ranking order, and data states.
